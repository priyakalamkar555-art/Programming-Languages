# 1) Variables In C++
Variables are container that hold data for your program.

Example: int age = 20;
##  Real Life Analogy
A variable like a labeled box

- Label = Variable Name
- The item inside the box = Values ( you can change the item anytime )

# 2) Data Types in C++
- Data types define what kind of data a variable can store.
- Decide the size & type of data a variable holds.

## Real Life Analogy
Data Type = different container for different items.
- A water bottle -> for liquid
- A box -> for solid items
- A book -> for words
